# Contributing to AI Design Kit

Thanks for your interest in contributing!

## Ways to help

- Add new color utilities or harmony schemes
- Improve or expand prompt templates
- Add more layout helpers
- Write additional examples or demos
- Improve documentation
- Report bugs or suggest features

## Development

```bash
npm run example    # run the basic usage example
npm test           # run tests
```

## Pull requests

1. Keep changes focused
2. Add or update tests when changing core utilities
3. Update the README if you add new public APIs

Looking forward to your contributions.
